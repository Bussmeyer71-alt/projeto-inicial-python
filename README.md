# Projeto Inicial - Utilitários de Cálculo em Python

Este projeto foi desenvolvido como parte do **Projeto Integrador - Fase 1** da Gran Faculdade.

## 📌 Descrição
O projeto consiste num script em Python que executa operações utilitárias do dia a dia, como o cálculo de médias académicas e a aplicação de descontos percentuais.

## 🚀 Funcionalidades
- Cálculo automatizado da média de notas.
- Cálculo de descontos em valores monetários.
- Estrutura modular em funções reutilizáveis.

## 🛠️ Tecnologias Utilizadas
- Python 3
